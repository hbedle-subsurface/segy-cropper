SEG-Y Cropper

Open your SEG-Y volumes, look at inlines, crosslines and time slices, draw a crop, and save cropped SEG-Y files. Everything runs on this computer; nothing is uploaded.

1 · Files

Changing a byte location re-reads the files. All files should be on the same grid; the crop is given in inline, crossline and time numbers and applied to each file.

    Choose one or more SEG-Y files.

    2 · Crop

    Drag a box on the view to set two of the ranges, or type them.

    Inline
    Crossline
    Time (ms)

    3 · Save

    Headers are copied from each input; the sample count and start time are updated. Samples are copied byte for byte (same format as the input).
